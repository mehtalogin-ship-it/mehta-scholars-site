# Harker Venture Investment Initiative — Mehta Scholars

Freestanding static rebuild of mehtascholars.com (no Wix). Plain HTML/CSS/JS.

## Structure
- `index.html`, `about.html`, `alumni-companies.html`, `our-investments.html`, `committee-list.html`, `updates.html`
- `companies/*.html` — per-founder/company detail pages
- `css/styles.css`, `js/main.js`, `assets/` (people photos + company tiles)
- `captured/` — source data (JSON) the generator reads
- Site is generated by a Python script from `captured/*.json`

## Preview locally
```
python3 -m http.server 8090
```
then open http://localhost:8090

## Deploy
Static — point Netlify or Cloudflare Pages at the repo root (publish `.`, no build).
Do NOT change DNS until ready to cut over from Wix.
